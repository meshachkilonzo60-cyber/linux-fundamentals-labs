# Linux Fundamentals Lab 01: Basic Commands

## Objective
Learn basic Linux terminal commands for navigation, system information, and command-line operations.

## Environment
- Operating System: Kali Linux
- Shell: Bash
- Skill Level: Beginner

## Commands Practiced

| Command | Description |
|---|---|
| `pwd` | Displays the current working directory |
| `ls` | Lists files and directories |
| `ls -la` | Displays all files, including hidden files, with details |
| `cd` | Changes the current directory |
| `clear` | Clears the terminal screen |
| `whoami` | Displays the current username |
| `uname -a` | Displays system and kernel information |
| `date` | Displays the current date and time |
| `man` | Opens the manual for a command |
| `history` | Displays previously executed commands |

## Practical Exercises

### 1. Identify the current directory
```bash
pwd
```

### 2. List directory contents
```bash
ls
ls -la
```

### 3. Navigate directories
```bash
cd Documents
cd ..
```

### 4. Identify the current user
```bash
whoami
```

### 5. Display system information
```bash
uname -a
```

### 6. Display date and time
```bash
date
```

### 7. Learn command documentation
```bash
man ls
```

### 8. Review command history
```bash
history
```

## Key Lessons
- Linux commands are case-sensitive.
- `pwd` shows where you are.
- `ls` helps you inspect directories.
- `cd` allows navigation through the filesystem.
- `man` provides built-in documentation.
- The terminal is a powerful interface for system administration and cybersecurity.

## Cybersecurity Relevance
Linux command-line knowledge is essential for cybersecurity professionals working with servers, security tools, log files, system administration, penetration testing, and incident response.
